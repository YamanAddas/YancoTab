Roadmap

The other 16 apps — innovation pitches

cosmic-native concepts · pick what excites you
N

Notes — Constellations

Productivity

Notes float as star nodes on a zoomable cosmos. Tags become constellations — drag a tag to merge notes into a cluster. Backlinks draw teal threads between stars.

  • Pin = becomes a brighter "anchor star"
  • Search collapses the cosmos to a focused beam through matching nodes
  • Pomodoro integration: a 25-min ring orbits the active note while you write
  • Hex sticker palette for moods (idea / draft / done / archived)
T

Todo — Mission Control

Productivity

Lists become missions; tasks are countdown rockets on a timeline. Drag a task up the launchpad to mark "today"; watch it lift off when checked.

  • Due dates as orbital decay — tasks dim & redden as they overrun
  • Priority = altitude on the launchpad column
  • "Streak" trail glow for daily recurring tasks
  • Weekly review = constellation of completed missions, exportable as Notes
P

Pomodoro — Solar Cycle

Productivity

Focus session = day. Break = night. The whole shell theme literally shifts: stars come out during breaks, sunrise gradient at session start. Treats focus as a daily rhythm, not a stopwatch.

  • Session ring orbits the dock; tap any app to attach the timer to it
  • 4-cycle "season" view — your week as four planetary loops
  • Optional ambient: deep-space drone ↔ solar wind
  • Auto-mute notifications during focus, restored at break
C

Calculator — Tape

Utility

Always-visible scrollable tape on the right; every line is editable and re-runs the chain. Inline unit conversion (12 mi in km), currency (100 USD in SYP), date math (today + 90d).

  • Variable assignment: tax = 0.16
  • Hex grid keypad (the brand made literal)
  • Tape auto-saves to Notes as a "calc journal"
  • Programmer / scientific modes via swipe
B

Browser — Wormholes

Utility

Bookmarks aren't a folder tree — they're portals arranged on a star map. Drag related sites near each other to form clusters. Recently-visited sites have a fading trail.

  • Tab groups become shared orbits
  • Reader mode strips chrome and renders into the cosmic palette
  • "Send to Notes" pulls highlights as star-node quotes
  • Per-site favicon hex frames everywhere — consistency win
F

Files — The Vault

Utility

A virtual FS rendered as a hex honeycomb. Each cell is a folder; nest by zooming in. Files float as small hex coins; drag-stack to create folders.

  • Universal preview pane: text, image, audio, PDF — same teal frame
  • Smart "rooms": Recent / Pinned / Heavy / Forgotten
  • Drag any file onto Notes/Todo/Browser dock icons → opens inside
  • Storage usage as a fuel gauge, not a percentage
S

Settings — Mission Console

System

Settings as a spaceship console. Toggles are physical-feeling switches; every change shows a 1-line confirmation in the status pill. Wallpapers preview live behind a portal cutout.

  • "Quick rituals": one-tap night mode, focus mode, weekend mode
  • Privacy panel front and center — show what doesn't leave the device
  • Sync diagnostics with timestamps and chunk counts (devs love this)
  • Easter egg: long-press the YancoTab logo to flip the whole shell upside-down
M

Maps — Atlas

Utility

Dark cosmic map style — teal roads, violet water, amber landmarks. Search a city → it lights up with current weather, time, and a "send to Clock world list" action.

  • Layers: Streets / Stars (light-pollution overlay) / Weather / Air
  • "Now" pin shows your local sunrise/sunset arc on hover
  • Save places into hex-coin "pinboards"
P

Photos — Lightbox

Media

Photos sit in a hex grid lightbox with edge-to-edge focus mode. Auto-organized by month → constellation thumbnails on the timeline scrubber.

  • Drop into Notes as inline cards
  • One-tap "set as wallpaper" with cosmic vignette
  • Faces and places clusters (local-only ML, optional)
P

PDF Reader — Codex

Media

Two-page spread on dark canvas with teal selection. Highlight → "send to Notes as quote-star". Outline = vertical orbit on the left edge.

  • Inline calculator + dictionary on selection
  • Reading-streak heatmap in the title bar
  • Picture-in-picture mini-window for cross-referencing
S

Solitaire — Cosmic Felt

Game

Same Klondike rules; cards float on starfield felt, gentle parallax. Suits keep the iconic red/black, but with subtle teal edge-glow on legal moves.

  • Daily "constellation deal" with seed code — share & compete
  • Win animation: cards fly off as a comet shower
  • Stats orbit: streak, best time, perfect-game count
S

Spider — Webwork

Game

Same engine as Solitaire, web-themed. Subtle silver thread auto-draws between cards in a valid sequence — visual tutoring without being a hint.

  • 1 / 2 / 4-suit difficulty as orbital "zones"
  • Undo with a faint phantom-card trail
M

Mahjong — Stoneworks

Game

Real ivory tile lighting, every match emits a teal ripple and a soft chime. Layouts unlock as constellations on a star map.

  • "Pair lens" — toggle to dim non-matching tiles, accessibility win
  • Hint = a faint orbital line between two tiles
  • Daily layout, share seed
M

Memory — Mirror

Game

When you flip a card, its twin briefly glints in your peripheral vision — rewards observation, not luck. Difficulty knob disables this.

  • Card backs are constellations; faces are app icons (a brand love-letter)
  • Time-attack vs. zen modes
S

Snake — Comet

Game

Snake is a comet with a fading trail. Apples are stars; eat them to grow. The world wraps; speed scales with score; trail length is your lifeline.

  • Power-ups as planets (x2 score / slow-mo / shield)
  • Boss every 1000 pts: a black hole that pulls you
  • Leaderboard "all-time orbit"
T

Tic-Tac-Toe + Tarneeb + Trix — The Table

Games

All three table games share a circular cosmic table shell — same chrome, same chip vocabulary. Tarneeb/Trix get a real Levantine flourish: Arabic court-card art option, Eastern numerals toggle, classic café green felt as an alt theme.

  • Personality AI opponents with names & quirks ("Abu Khalil bids cautiously")
  • Bid tracker / trick history orbits the table edge
  • Local 2-player passing-the-laptop mode with privacy curtain
  • Tic-Tac-Toe gets a 5×5 / Ultimate variant for veterans
★

Cross-app moves — things only YancoTab can do

Shell

The reason this is a desktop, not 18 separate pages.

  • Drag-anywhere: drop a Photo onto Notes (inline), onto Files (saved), onto Browser (search by image), onto Wallpaper (set instantly)
  • Hex stickers: a shared 8-color sticker palette colors notes, todos, files, places, tabs — one mental model, one keyboard shortcut
  • Mission mode: pick an app + Pomodoro + a playlist; shell dims, dock collapses, "do not disturb" pill appears, status bar shows mission countdown
  • Daily ritual on every new tab: 1-line "good morning, here's your day" — weather + first todo + first calendar item, all from existing apps
  • Universal ⌘K over everything: apps, notes, todos, files, calc expressions, weather queries, world clocks. One bar to rule them all
  • Export-as-portal: share any state (a Tarneeb game seed, a Solitaire deal, a Snake replay, a note) as a tiny URL that opens that exact state in another YancoTab
